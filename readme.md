# MUSE'S BLOOM: ORDERS DASHBOARD
- The front end of the order dashboard for a flower shop app

- It has three JSON files; customers, products and orders, all linked with JS.

- The order stores only the ids. the customers details are in the Json files.

# FEATURES:
- Indicators: customers, products, orders, total amount

- Search by customer name

- Filter by status and by category

- Order detail window
